For church website editors with repository write access. Your connection key stays in this tab’s memory and is cleared when you sign out or reload.

First time? Set up access
  1. The repository owner invites each editor to Zayaiken21/The-growing-Church as a GitHub collaborator.
  2. In your GitHub account, create a fine-grained access token ↗. Select only this church repository, with Contents: Read and write. Optionally allow Actions: Read to see publishing progress.
  3. Choose an expiration, copy the token and paste it above. The owner may need to approve access. Never share your token.

If GitHub does not offer this repository for a fine-grained token, ask the owner to set up organization access; collaborators on personal repositories can have token limitations. A classic token with public_repo is an alternative, but covers all public repositories you can write to.

GitHub handles your account password, two-factor authentication and account recovery. This editor does not create separate church passwords.
